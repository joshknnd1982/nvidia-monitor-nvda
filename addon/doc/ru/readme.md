# NVIDIA Monitor

Это дополнение позволяет отслеживать различные параметры видеокарт NVIDIA, такие как имя, используемая память, свободная и общая память, энергопотребление, температура и другие.

## Сочетания клавиш

Примечание: некоторые информационные параметры могут не поддерживаться в зависимости от видеокарты.
Все следующие сочетания клавиш можно настроить в категории «NVIDIAMonitor» диалога «Жесты ввода». Двойное нажатие копирует информацию в буфер обмена.

- NVDA + alt + g: Объявляет имя/модель графического процессора.
- NVDA + alt + u: Объявляет UUID графического процессора.
- NVDA + alt + v: Объявляет версию драйвера.
- NVDA + ctrl + alt + v: Объявляет версию BIOS.
- NVDA + alt + 1: Объявляет о загрузке графического процессора.
- NVDA + alt + 2: Объявляет о загрузке памяти.
- NVDA + alt + 3: Объявляет о свободной памяти.
- NVDA + alt + 4: Объявляет используемую память.
- NVDA + alt + 5: Объявляет общий объём памяти.
- NVDA + alt + 6: Объявляет температуру графического процессора.
- NVDA + alt + 7: Объявляет о потреблении энергии.
- NVDA + alt + 8: Объявляет о пределе энергопотребления.
- NVDA + alt + 9: Объявляет количество процессов CUDA.
- NVDA + alt + 0: Объявляет память, используемую процессами.
- NVDA + ctrl + alt + 1: Объявляет скорость вращения вентилятора.
- NVDA + ctrl + alt + 2: Объявляет тактовую частоту графического процессора.
- NVDA + ctrl + alt + 3: Объявляет максимальную тактовую частоту графического процессора.
- NVDA + ctrl + alt + 4: Объявляет тактовую частоту SM.
- NVDA + ctrl + alt + 5: Объявляет максимальную тактовую частоту SM.
- NVDA + ctrl + alt + 6: Объявляет тактовую частоту памяти.
- NVDA + ctrl + alt + 7: Объявляет максимальную тактовую частоту памяти.
- NVDA + ctrl + alt + 8: Объявляет пропускную способность TX.
- NVDA + ctrl + alt + 9: Объявляет пропускную способность RX.
- NVDA + ctrl + alt + 0: Объявляет о состоянии питания.


## Журнал изменений

### Версия 2.1.1

- Добавлен русский перевод.
- Исправлена ошибка, из-за которой сообщение могло вообще не объявляться,
  когда дополнение сообщало о проблеме на языке, символы которого не
  поддерживаются кодовой страницей системы.

### Версия 2.0

- Совместимость с NVDA 2026.1.
- Начиная с этой версии, при работе в последней версии NVDA дополнение обращается к библиотеке pynvml напрямую, а не через внешнюю программу.

### Версия 1.0

- Несколько изменений, исправлений и улучшений были внесены в скрипт, из которого берётся информация.
- Ошибки теперь записываются в файл NVIDIAMonitor.log, расположенный в папке конфигурации NVDA.
- Совместимость с NVDA 2025.1.
- Некоторые существующие сочетания клавиш были переназначены.
- Добавлены новые сочетания клавиш:
  - UUID графического процессора: NVDA + alt + u
  - Версия драйвера: NVDA + alt + v
  - Версия BIOS: NVDA + ctrl + alt + v
  - Загрузка памяти: NVDA + alt + 2
  - Предел энергопотребления: NVDA + alt + 8
  - Память, используемая процессами: NVDA + alt + 0
  - Максимальная тактовая частота графического процессора: NVDA + ctrl + alt + 3
  - Тактовая частота SM: NVDA + ctrl + alt + 4
  - Максимальная тактовая частота SM: NVDA + ctrl + alt + 5
  - Тактовая частота памяти: NVDA + ctrl + alt + 6
  - Максимальная тактовая частота памяти: NVDA + ctrl + alt + 7
  - Пропускная способность TX: NVDA + ctrl + alt + 8
  - Пропускная способность RX: NVDA + ctrl + alt + 9
  - Состояние питания: NVDA + ctrl + alt + 0

### Версия 0.2

- Двойное нажатие сочетания клавиш теперь копирует информацию в буфер обмена.
- Различные улучшения и оптимизации.

### Версия 0.1

- Первоначальная версия дополнения.
